Definition: git status

The `git status` command shows the current state of the working directory and the staging area. 
It provides information on which changes are staged for commit and files that are untracked. 
This command is useful to review what changes have been made before committing them.

In JupyterLab, the same information can be accessed using the Git extension on the left sidebar. 
It shows modified, staged, and untracked files, and allows staging and committing changes instead of the terminal.
