# Definition: git-status

The `git status` command shows the current state of the working directory and the staging area.  
It tells you which changes are staged for the next commit, which files are modified but not yet staged, and which files are untracked.  

This command is useful to check what Git thinks has changed before committing.  

In JupyterLab IDE, you can see the same information in the Git extension panel on the left. It visually lists modified, staged, and untracked files, instead of typing `git status` in the terminal.
