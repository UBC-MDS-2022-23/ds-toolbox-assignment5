# Definition: git status

The `git status` command shows the current state of your working directory and staging area. It tells you which files have been modified, which changes are staged and ready to be committed, and which files are untracked. It's a completely safe command to run since it only reports information — it never changes anything in your repository.

If you were using the JupyterLab IDE instead of the terminal, you can get the same information visually through the Git panel in the left sidebar, which shows your changed, staged, and untracked files as separate lists instead of printing them as text.
