# Definition: git status


The git status command to displays the state of your working directory and staging area. It lets users see which changes have been staged, which haven't, and which files aren't being tracked by Git. This provides a quick summary of the current state of a project, helping you understand what will be included in your next commit.

In Jupyter Lab, this same functionality can be achieved using the Git extension. This integrates a GUI displaying all the same information in the left panel.
