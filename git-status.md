## Definition: git status
 
1. ***Explain what the git status command is useful for***

This command is useful for checking the status of all files in the current repository, such as untracked, changed, or staged.

2. ***How can you access the same information provided by this command if you were using the JupyterLab IDE instead of the terminal?***

Click Jupyter Git extension icon on the left sidebar and the side panel will show the same information.
