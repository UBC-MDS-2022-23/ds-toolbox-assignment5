# Definition: git status
The git status is used to show the current state of the current directory and to show the staging area in Git repository. It is helpful to understand what changes have been staged, what changes are in the directory and also what changes aren't tracked by Git yet. 


When using JupyterLab IDE, the same information can be accessed by opening the terminal within JupyterLab and running the git status command. JupyterLab provides an integrated terminal where you can run Git commands just like in the system terminal. This allows you to check the status of your repository and manage your version control without leaving the JupyterLab interface.
