# Definition: git status

In a git project, the `git status` is a useful command that shows the current status of the working directory. It shows information such as changed files, staged files that are ready to be committed and untracked files.

It is useful for the user to clearly visualize what branch it is currently on, which files have been changed and ready to be staged, and which files are staged and ready to be committed.

If you are using the JupyterLab IDE, you can access the same inforamtion provided by `git status` by clicking on the git tab.
