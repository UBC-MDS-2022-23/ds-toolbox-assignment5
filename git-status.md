## Definition: git status

The **git status** command will display the current state of the files in the working directory and the staging area. The command shows which files are tracked and what changes are present in the staging area

#### How to access the same information using the JupyterLab IDE
- *Click the folder tab on the left hand side*
- *Set your working directory to the location of the cloned repository*
- *Click the git tab on the left hand side*
- *The **Current Repository** and **Current Branch** will be displayed at the top*
- *Click **Changes** and it will show which files are **Staged**, **Changed** or **Untracked** under the corresponding drop down*

#### Steps to commit changes using the Terminal
1. *Add the file to the staging area using **git add [filename]***
2. *Commit the change using **git commit -m "[commit message]"***
