# **Definition:** git status  

The *git status* command allows us to see an summary of our current working directory and the current branch, files we have been working on, and whether the files have been staged or tracked.

While we can use this in the terminal, JupyterLab has an extension that can be installed. After installing this extension, the *git status* panel allows us to view the same information, but formatted in a user-friendly way. It also provides shortcuts to Git commands through the user interface in the panel.
