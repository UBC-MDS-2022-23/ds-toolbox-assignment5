# Definition: git status

-  Displays the number of commits made, if there is one, for current branch .
-  Displays the untracked files that is not commited by Git.

Benefit of 'git status' command as follows
1. Before making any change, user can check if cloned repository is upto date with the remote repository.
2. Before making commit, user can check if there is untracked file that needs to be staged.
3. Before pushing the commit, user can add more commits from above mentioned untracked files.

Similar functionality can be done in JupyterLab IDE.
On git tab, there is changes section that can be expanded.
From here, user can check if the local repo is upto date with the remote repo, in terms of commits.
Under untracked, any changes for the files in the PATH can be staged and commited.
