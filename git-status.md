# Definition: git status

The git status command is used to check the current "health" or state of your repository. It provides a quick summary of which branch you're currently working on, whether your local files are synced with the remote version, and which specific files have been modified, staged for a commit, or left untracked. It’s a vital tool for double-checking your work before you commit or push, to make sure you don't accidentally include files you didn't mean to or forget a crucial change.

If you're working in JupyterLab instead of the terminal, you can find this same information in the Git extension panel on the left side of the screen.

In the git panel, the interface visually breaks down the information that git status would normally output as text. You’ll see lists for Changed, Staged, and Untracked files, allowing you to manage your version control through a graphical interface rather than typing commands into the terminal.
