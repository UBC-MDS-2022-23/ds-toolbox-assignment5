#Definition: git status

Git status is mainly used to show te state of git repository. By using this command you are able to see whether changes have been staged, not been staged, and files that git is not tracking. This is useful, as you can see info about your files before you decide to push or commit new files. 

Jupyterlab offers similar functionality by using the Git extension, it shows a visual cue with different section for files changes.
