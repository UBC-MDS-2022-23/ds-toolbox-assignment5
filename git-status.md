# Definition: git status

The `git status` command displays the state of your working directory and staging area. It identifies modified, staged, and untracked files, while showing your current branch and synchronization status with the remote repository. It is essential for inspecting changes before committing.

In JupyterLab, access this information via the **Git tab** (branch icon) on the left sidebar:

* **Header:** Displays active branch and remote sync status.
* **File Lists:** Categorizes changes into **Staged**, **Changed** (Unstaged), and **Untracked** sections.
* **Status Badges:** Uses letter badges (**M** for Modified, **U** for Untracked, **A** for Added) next to filenames for quick inspection.
