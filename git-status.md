Definition: git status

The git status command is used to see the current status of the git repository you are in. It shows which changes have been staged and committed, and tells you if there are any untracked files. It also shows whether the local repository is up to date with the remote repository, and if there are changes to be pushed or pulled. 

To find the same information using the Jupyter Lab IDE, you can click the git icon in the left toolbar and go to the Changes tab.
