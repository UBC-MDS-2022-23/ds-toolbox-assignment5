Definition: git status
Git status shows you the current state of the repo you're working in. It will show you the status of files you're working on, whether they're staged, committed, or not committed, or files with changes that aren't tracked yet. I don't think you can access the same information all in the same place with the jupyter ide, but you can still view most of it. The current branch and repo are on the toolbar on the left hand side. You can see which files have been changed, staged, and which files are untracked in the changes tab. Your history is also available in the tab next to changes.
