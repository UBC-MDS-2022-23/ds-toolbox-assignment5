# Definition: git status

***Displays paths that have differences between the index file and the current HEAD commit, paths that have differences between the working tree and the index file, and paths in the working tree that are not tracked by Git.***

## How to use the Git extension JupyterLab IDE
    1.  Open the Git panel. In the left-hand sidebar of the JupyterLab interface, click the Git icon (the branching circles icon).
    2.  View the repository status. The Git panel will open, showing you the status of your current repository. It displays files       
        grouped by their status, such as "Untracked," "Changed," and "Staged". This provides the same information as the git status command, but in a graphical format.
    3.  Perform Git actions. From this panel, you can stage, un-stage, or discard changes by clicking the icons next to the file names.
