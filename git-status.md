# Definition: git status

The command `git status` can be used for showing the following information (paraphrased from /git-doc/git-status.html): 
1. The path that has differences between the index file and the current head commit.
2. Paths that have differences between the working tree and the index file
3. Untracked files in the current branch.

The information displayed by `git status` can also be accessed in the "Changes" section of the Git menu within the JupyterLab IDE.
