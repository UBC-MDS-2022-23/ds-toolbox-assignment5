# Definition: git status

The `git status` command shows the current state of your local repository. 
It tells you which changes have been staged, which haven't, and which files aren't being tracked. 
It also tells you what branch you are on and whether your branch is ahead, behind, or up to date with the remote.

In JupyterLab, you can access similar information by using the Git extension panel, 
which shows unstaged changes, staged changes, and the current branch.
