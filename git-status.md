Definition: git status

git status is used to provide a summary of:
- the branch currently being used
- if if the local branch is up to day, behind, or ahead of the remote repository

git status also provides a summary of the file inluding:
- to be committed
- changes not staged for commit
- changes made but not stages (untracked files)

When using the JupyterLab IDE the same information is provided in the changes tab of the git repository.
