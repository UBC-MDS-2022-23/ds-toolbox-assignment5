# The "git status" command
The `git status` command is used to return the status of the branch you're currently working   
on and the status of files in the repository. The output summarizes information including the  
how the branch compares to the remote repo, tracked and untracked files, any merge conflicts  
and the commits adding to the staging area.  
You can view the same information in JupyterLab via the Git side menu, under "Changes".
