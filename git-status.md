"Definition: git status"

As the name implies, the git status command will give you the current status of your current branch. Thats is to say, it will tell you whether your current branch is ahead or behind(in terms of changes made) from the remote repository. It will also give you detailed information on which files have changes that are untracked, which are staged and noy yet commited, and which have already been comitted. 

We can install an extension called "Git extension" that will act as a live graphical version of git status. It will display the current branch, staged changes, unstaged/modified changes, and untracked files, just like git status would.
