### Definition: git status
The command git status allows you to check the repo status and it is very handy if you are not sure what to do next.
To access the same information provided by this command using the JupyterLab IDE look at the left sidebar for the Git icon.
Click it, and you’ll see:
- Untracked files
- Modified files
- Staged files
- Branch name
- Changes summary
This panel is essentially a visual version of git status.
