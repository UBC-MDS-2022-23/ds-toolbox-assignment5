# Definition: git status
*git status* is a command that reports the current working environment within your repository. It highlights the current branch you are working on, and highlights the difference between the latest commit and your current progress, i.e. what changes have been made, and what files are being/ not being tracked by Git. 

Within the JupyterLab IDE, a Graphical Interface, indicated by a photo of a Graph within a Gray Diamond on the left side of the IDE, can be used to monitor similar information reported by *git status*
