The ___git status___ command displays the current state of your working directory and staging area. 
It shows which files are modified, staged for the next commit, or untracked, making it essential for verifying your changes before saving them.

In JupyterLab, you can view this exact information without the terminal by clicking the Git icon in the left sidebar. 
This opens a visual panel that lists your changed, staged, and untracked files in real time.
