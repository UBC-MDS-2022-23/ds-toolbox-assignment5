# Definition: git status

The git status command outputs information that details the current state of the repository. 

The command git status is useful for knowing where HEAD is pointing, whether there are any changes in the current directory which have not yet been committed or staged, and if a local branch is ahead of or behind the remote branch by any commits. Another useful function of the information provided by git status is that it can help determine where which files contain conflicts when there are merge conflicts.
