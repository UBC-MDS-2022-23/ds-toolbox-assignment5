# Definition: git status

The git status command is used to check the current state of the directory's files and staging status. This is useful to see
if there are files that are untracked, changed and not staged, and staged/ready to commit. It also shows whether the current
working directory is ahead or not of the origin/main. When using JupyterLab IDE instead of terminal, this information can be
found by clicking the Git button on the left-hand side of the page and navigating to the resulting page. This shows the Staged,
Changed, and Untracked changes of the files in the current working directory.
