<h1>Definition: git status</h1>
<br>
Git status is very helpful GIT command to see changes and to understand how synchronized is our local repo to the online repo.
In a terminal you can see:
<lo>
    <li>Commit status</li>
    <li>Pending commits, push</li>
    <li>Changes on the online repository that are not up to date in your local repo</li>
    <li>etc</li>
</lop>

On Jupyter IDE you can see under changes to understand the state of your local repository
Under changes you will see the following options:
<ol>
<li>Staged</li>
<li>Changed</li>
<li>Untracked</li>
</ol>

Also you can inspect quickly the status of the Pull and Push icons to understand how synchronized is our local repo to the online repo.
