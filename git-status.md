
# "Defintion: git status" #

The git status commmand used in terminal allows you to look up what is currently awaiting your action for a directory. If files have been changed but not staged or committed, it will inform you that these actions are awaiting your attention. It also tells you which branch you are working in. 

The equivalent to this in jupyter  is to go to the git > changes/history/current branch to get the same information
