# Definition: git status 

The <em>git status</em> command helps to undertand the state of the working directory and branch you are working on. It will display a lits of the changes that have been stage, witch are pending, and if you have untrack files. 

Using the IDE: On the left side of Jupyter Lab go to Changes, there you'll have a display of each state your working files may be in. 

Using the terminal: Type $git status
