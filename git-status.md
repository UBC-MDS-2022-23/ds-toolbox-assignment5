#Definition:git status
The git status command displays the current status of the working directory, including what changes have been staged/commited. git status does not alter any files or their statuses, so it can be used to take inventory of the situation without fear of altering something unknowingly. git status also tells you the state of your local working directory relative to the github repository in the cloud. the Jupyterlab IDE shares a similar function in the source control panel on the left side of the window, which contains a number of helpful features for assessing the currect state of your work, including what files are staged/commited, and a history of past commits in the bottom left.
