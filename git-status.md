# Definition: git status

The command `git status` will give you the condition of all the files in your directory, whether Untracked, Changed or Staged. Depending on your file status - as described previously - this command will also indicate the following command to use (to stage or commit your file). 

In other words, this command checks your staging area, which is good practice to do before committing.

The same information can be found on the Changes tab of the Git extension tab in JupyterLab IDE.
