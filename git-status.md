# Definition: git status
git status tells you what’s going on in your Git repository right now.
This is a great way for an individual to see untracked, changed, staged files with hints on next command to run for a commit to be finally made.
### Using JupyterLab IDE
In Jupyter Lab, we can follow the following steps to achieve the same purpose that git status provides:
1. Look at the left sidebar in JupyterLab IDE.
2. Click the Git icon with the branch symbol.
3. In the panel, we can see a graphcial version of the results from git status, showing changed, staged, untracked files.
