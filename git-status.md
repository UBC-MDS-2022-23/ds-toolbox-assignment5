# Definition: git status

### The Git command `git status` provides an overview of the current state of the working directory of the repository you are working in. The information provided by this command can be as simple as indicating whether the repository is up-to-date in commits, whether files have been staged or not, and the status of tracked or untracked files in the .git folder. 

### The same information can be seen in the Git sidebar in a Jupyter Notebook. Pressing the left-hand Git icon will open a side bar. The **Changes** section of this area displays similar data as the `git status` command in real time.

### It is considered a good habit to check the 'git status' in terminal before each new commit to ensure that the action on the files is what was intended.
