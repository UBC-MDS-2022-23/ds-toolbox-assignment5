# Definition: git status


### 1. What is the `git status` command useful for?


The `git status` command is used to display the current state of your working directory and staging area.

**It helps you understand:**

1) Which changes have been staged
2) Which have not been staged
3) Which files are not being tracked by Git


### 2. How to view `git status` information in JupyterLab IDE


In JupyterLab, you can view the same Git information without using the terminal. 

**If you haven't installed the Git extension, be sure to install it first to easily view your repository status.**

1. Open JupyterLab
2. Click the Git panel on the left sidebar in the JupyterLab IDE.
3. The panel shows Staged Changes, Unstaged Changes, Untracked Files, Current Branch, and Commit Status
