Definition: git status

The git status command shows which branch I am working on and whether I have changed files, staged changes, or new files that Git is not tracking. It is useful for checking what is ready to commit and what still needs to be added to the staging area.

In JupyterLab, I can view this information by opening the Git panel in the left sidebar. It shows the current branch and lists files under Changed, Staged, and Untracked.
